# 《百年星语·破晓 1928》剧本站

云南本土原创红色音乐剧的剧本展示站，从剧本第 37 版（2025 年 11 月中稿）文档从零构建。不是官方宣传页，也不代替剧本。

## 打开

双击 `index.html` 即可，或在目录内起一个本地服务：

```
python3 -m http.server 8788
```

浏览器打开 `http://localhost:8788/`。字体与图片都是本地或白名单镜像，断网也能看到完整版式（字体回退到系统宋体）。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 单入口页面，8 个区块 + 5 个幕间全屏页 |
| `assets/style.css` | 全部样式：色板变量、区块样式、三档响应式、reduced-motion 降级 |
| `assets/app.js` | 原生 JS：区块入场、唱词逐句、分曲表筛选、第三颗星、幕间图漂移、导航态 |
| `assets/numbers.js` | `window.NUMBERS`，28 首曲目元数据（曲号/体裁/演唱者/调性/拍号/速度/时长） |
| `numbers.json` | 同上的 JSON 版，便于二次使用 |
| `design-spec.md` | 设计规格书：每个色值、字体、质感、动效、配图的剧本出处 |
| `script.txt` | 从 docx 解出的全文纯文本，2027 行 |
| `img/` | 4 张真实照片 + `meta.json`（来源、作者、许可） |
| `预览/` | 桌面与手机截图三张 |

## 页面顺序

1. Hero：剧名、双时空定位、四格数字、马灯照片
2. 原创团队条：云南民族大学马笛红色音乐剧原创团队，编剧白耀洲、孙子岚，作曲彭侠颖
2. 01 剧情简介：四段梗概 + 一句剧本原话
3. 02 人物表：历史线 19 人（全唱）／现代线 9 人（全说白）／叙述者 1 人
4. 03 分幕：序幕、第一至三幕、终幕上、终幕下（六幕），左竖排幕题 sticky，右剧情点与唱词
5. 幕间 5 页：灯／谷／织／血绢／楹，各一句剧词
6. 04 唱段精选：No.19 血绢誓、No.18 坐牢也是战斗、No.27 第三颗星，逐字原文
7. 05 分曲表：28 首，可按体裁筛选，总时长 120′50″
8. 06 年表：1927.2 创刊 → 2026 夏
9. 07 第三颗星：红心布 SVG，点第三颗星出「念」与两张压着的纸
10. 08 原创团队·制作：团队名与编剧、作曲、剧本版本三栏大字，下接剧末声明与图片授权
11. 页脚：巨号剧名、四列 meta、逐张图片致谢

## 事实口径

- 唱词、台词、人物、时间点全部取自第 37 版（2025 年 11 月中稿），未润色、未补写；剧本没写的留白。
- 曲目 28 首 = No.1–27 + No.16B（原稿编号即如此，不补 No.25）。
- 唱段总时长 120′50″（28 首逐条累加）；No.1 3′30″、No.2 4′00″，均按剧本正文录入。
- 封面署名原文「云南民大学院马笛团队」；按剧方确认，站内统一为「云南民族大学马笛红色音乐剧原创团队」，署名差异在 08 说明中写清。
